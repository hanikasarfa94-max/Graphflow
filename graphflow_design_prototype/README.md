# GraphFlow Design Prototype

This folder contains:

- `design.md` — English design specification, page model, interface contract notes, and API protocol suggestions.
- `src/main.tsx` — React + TypeScript high-fidelity prototype.
- `src/styles.css` — visual system and layout styles.
- `package.json` — Vite app configuration.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Notes

- The prototype is static and uses mock data.
- The API contracts in `design.md` are intended to help map the prototype into an existing codebase.
- The color palette intentionally avoids the earlier brown/terracotta-heavy direction and uses a cooler graphite / blue / violet / mint system.
